Historical learning application. Sensor names are anonymized. Class 0 denotes failures unrelated to APS, not a healthy vehicle. Use valid source-format sensor exports; no diagnostic or safe-to-drive claim is made. Feature values stay in your browser; this app has no inference API or upload endpoint.

Defaults combine training medians and common categories. They do not identify a source person, vehicle or tested mixture. Blank numeric fields use training-only imputation.

Second profile: compare a what-if

02 / BATCH

Work with a source-format CSV

Use all named feature columns, up to 500 rows and 2 MiB. Blank fields represent missing observations. Predictions are calculated in a local Web Worker; exported rows contain predictions rather than copying your input features.

03 / EVIDENCE

Model selection and held-out evaluation

Preprocessing is fitted on training data only. Validation selects the algorithm and classification threshold. The published test set is held out. These are retrospective source-data results, not guarantees for a new population.
